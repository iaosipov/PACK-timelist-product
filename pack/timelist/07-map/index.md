# Map — TimeList Product

## Product Map

```
┌─────────────────────────────────────────────────────────────────┐
│                         TimeList Product                          │
├─────────────────────────────────────────────────────────────────┤
│  Capture Layer (захват)                                           │
│  ├── Бот TimeList в ВКС (GT, TrueConf, Яндекс Телемост)         │
│  ├── Браузерное расширение                                        │
│  ├── Загрузка готовой записи (до 6ч / 3ГБ)                        │
│  └── Диктофон / спикерфон                                         │
├─────────────────────────────────────────────────────────────────┤
│  Processing Layer (обработка)                                     │
│  ├── Распознавание речи                                          │
│  ├── Идентификация спикеров                                        │
│  ├── Стенограмма (дословный текст)                                │
│  └── Автопротокол (решения, поручения, сроки)                   │
├─────────────────────────────────────────────────────────────────┤
│  Output Layer (выдача)                                            │
│  ├── Word / Excel экспорт                                         │
│  ├── AI-чат по встрече (до 5 встреч)                              │
│  ├── База знаний встреч (поиск, фильтры, теги)                  │
│  └── Импорт задач в Bitrix24                                      │
├─────────────────────────────────────────────────────────────────┤
│  Extensions (расширения)                                          │
│  ├── Корпоративный таймбот (Битрикс/Telegram/MAX)                 │
│  └── Задачник-ассистент (прототип)                                  │
├─────────────────────────────────────────────────────────────────┤
│  Deployment Modes                                                 │
│  ├── Облако (~100 руб/час, годовые пакеты)                        │
│  └── On-premise (серверы с GPU, пилот от 280 тыс./мес)          │
└─────────────────────────────────────────────────────────────────┘
```
