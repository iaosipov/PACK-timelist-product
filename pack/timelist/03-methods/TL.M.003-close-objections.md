# TL.M.003 — Закрытие технических возражений

## Summary

Работа с типовыми сомнениями до демонстрации, чтобы снизить сопротивление.

---

## Input

Типичные сомнения заказчика: безопасность, совместимость ВКС, точность, идентификация спикеров.

## Action

Заранее дать таблицу «возражение → ответ» по ключевым техническим вопросам.

## Output

Снижение сопротивления перед демонстрацией.
