# TL.M.006 — Пилот «TimeList + Bitrix24 + MAX-боты»

## Summary

Трёхнедельное ограниченное внедрение для 6–7 сотрудников заказчика.

---

## Input

Заказчик с 6–7 сотрудниками, готовый к 3-недельному пилоту.

## Action

1. Неделя 1 — аудит/настройка Bitrix24 и подключение бота.
2. Неделя 2 — обучение и внедрение.
3. Неделя 3 — контроль, корректировка, финализация.

## Output

Работающая система контроля поручений в Bitrix24 + прототип автоматизации из MAX + опробованный TimeList.

## Work Products Produced

- TL.WP.003 — Список поручений в Bitrix24
- TL.WP.005 — Памятка по регламенту работы с поручениями
- TL.WP.008 — Отчёт по задачам из MAX-чатов

## Failure Modes Addressed

- TL.FM.003 — Дублирование систем контроля задач
- TL.FM.004 — Слишком много новых сущностей одновременно
