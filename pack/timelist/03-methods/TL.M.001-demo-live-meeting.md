# TL.M.001 — Демо продукта на живой встрече

## Summary

Главный метод продажи TimeList: бот присутствует на демо-встрече и показывает расшифровку в реальном времени.

---

## Input

- Потенциальный заказчик.
- Активная ВКС-встреча.
- Бот TimeList.

## Action

1. Пригласить бота на демо-встречу.
2. Показать расшифровку в реальном времени.
3. Продемонстрировать разбивку по спикерам.
4. Показать авторезюме / протокол в разных форматах.
5. Продемонстрировать AI-чат по встрече.
6. Показать экспорт в Word/Excel и импорт задач в Bitrix24.

## Output

У заказчика — живое подтверждение качества и понимание сценариев использования.
