# TL.M.004 — Создание стенограммы через TimeList-бота

## Summary

Захват аудио с ВКС-встречи и получение дословной расшифровки с именованными спикерами.

---

## Input

Запланированная ВКС-встреча.

## Action

1. Пригласить бота TimeList на встречу.
2. Провести встречу.
3. Дождаться автоматической расшифровки.
4. Присвоить имена спикерам.
5. Проверить корректность.

## Output

Проверенная стенограмма с именованными спикерами.

## Work Products Produced

- TL.WP.001 — Расшифровка (стенограмма) встречи

## Failure Modes Addressed

- TL.FM.001 — Неверная идентификация спикеров
- TL.FM.002 — Непредсказуемый захват задач из протокола
