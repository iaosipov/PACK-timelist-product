# TL.FM.001 — Неверная идентификация спикеров

## Summary

Система неправильно распределяет реплики между участниками.

---

## Error

Система неправильно распределяет реплики между участниками встречи.

## Cause

- TrueConf без активных окон.
- Плохое качество аудио.
- Несколько человек говорят одновременно.

## Effect

Протокол приходится допиливать руками; снижается доверие к результату.

## Antidote

- Честно предупреждать о погрешности.
- Использовать ВКС с активными окнами (Evo).
- Вести культуру говорить по очереди.
- Ручная корректировка спикеров.
