# TL.FM.003 — Дублирование систем контроля задач

## Summary

Задачи одновременно ведутся в MAX и Bitrix24; сотрудники не понимают, где контролировать.

---

## Error

Задачи одновременно ведутся в MAX и Bitrix24, сотрудники не понимают, где им контролировать.

## Cause

Резкое внедрение новой системы поверх привычного чата без интеграции.

## Effect

Задачи теряются, снижается дисциплина, руководитель возвращается к ручному «пинанию».

## Antidote

- Подключить бота, который транслирует задачи из MAX в Bitrix24.
- Не ломать привычки, а надстроить отчётность.
