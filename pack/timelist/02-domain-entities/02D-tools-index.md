## What is a Tool

Per FPF/SPF: a **tool** is a concrete means (software, hardware, template) used to perform a method. A tool is not a method itself.

## Notes

- TimeList сам по себе — система, а не отдельный инструмент. Внутри него есть бот, кабинет, AI-чат, экспорт.
- Корпоративный таймбот — отдельный продукт/инструмент на базе TimeList.
- Задачник-ассистент — прототип, не вынесен в инструменты до статуса продукта.
