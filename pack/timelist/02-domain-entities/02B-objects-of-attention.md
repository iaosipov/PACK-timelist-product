## TL.ENT.001 — Встреча / совещание

**Definition**: Аудио/видео событие, которое TimeList фиксирует: онлайн через бота в ВКС или офлайн через запись.

**Attributes**:
- Дата и время
- Участники
- Спикеры
- Длительность
- Язык
- Источник (VKS-бот / файл / диктофон)

**Relationships**:
- имеет → TL.ENT.002 Стенограмма
- имеет → TL.ENT.003 Автопротокол
- порождает → TL.ENT.007 Поручение
- хранится в → TL.ENT.008 База знаний встреч

**Source**: `lespromhoz-timelist.md` + `transcripts/2026-06-08/1324-...txt`

## TL.ENT.002 — Стенограмма

**Definition**: Дословная текстовая расшифровка встречи с разбивкой по спикерам.

**Attributes**:
- Текст
- Тайм-коды (требует уточнения: в источниках сказано «нет пометок по тайм-кодам»)
- Спикеры
- Язык

**Relationships**:
- принадлежит → TL.ENT.001 Встреча
- может стать основой → TL.ENT.003 Автопротокол

**Source**: `DS-strategy/exocortex/reference_timelist_sales.md` + `lespromhoz-timelist.md`

## TL.ENT.003 — Автопротокол / авторезюме

**Definition**: Структурированный результат встречи (резюме, решения, форматы Word/Excel).

**Attributes**:
- Формат
- Список решений
- Список поручений
- Ответственные
- Сроки

**Relationships**:
- порождается из → TL.ENT.001 Встреча
- может экспортироваться в → Bitrix24

**Source**: `DS-strategy/exocortex/reference_timelist_sales.md` + `lespromhoz-timelist.md`

## TL.ENT.004 — Бот TimeList в ВКС

- Браузерное расширение

**Relationships**:
- присутствует на → TL.ENT.001 Встреча
- создаёт → TL.ENT.002 Стенограмма

## TL.ENT.006 — AI-ассистент / чат по встрече

- Теги

**Relationships**:

## TL.ENT.007 — Поручение / задача из протокола

**Attributes**:

- Дедлайн
- Статус
- Источник (из какой встречи)

**Relationships**:
- порождается из → TL.ENT.003 Автопротокол
- интегрируется с → Bitrix24
