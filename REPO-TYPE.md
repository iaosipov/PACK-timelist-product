# Тип репозитория

**Тип**: `Pack`

**Source-of-truth**: yes

## Область

**TimeList как продукт** — ИИ-сервис расшифровки аудио и автопротоколирования совещаний (timelist.ru, совместное предприятие с 1С).

Предметная область включает функциональность продукта, сценарии использования, роли пользователей, методы продажи и внедрения, типовые ошибки и конкурентное позиционирование.

## Upstream dependencies

- [TserenTserenov/SPF](https://github.com/TserenTserenov/SPF) — Second Principles Framework
- [ailev/FPF](https://github.com/ailev/FPF) — First Principles Framework

## Downstream outputs

- Материалы для продаж TimeList
- Обучающие материалы по продукту
- Интеграционные сценарии (Bitrix24, MAX, Telegram)

## Non-goals

- НЕ содержит исходный код TimeList
- НЕ содержит научную модель TimeInvest / МСВ (это отдельный PACK)
- НЕ описывает общую методологию тайм-менеджмента
- НЕ является документацией API
