# PACK-timelist-product

> **Тип репозитория:** `Pack`

> Pack (паспорт области) для предметной области «TimeList как продукт» — **source-of-truth** для знаний об ИИ-сервисе расшифровки совещаний и автопротоколирования.

## Что это

Формализованные знания о продукте **TimeList**: что он делает, для кого, как продаётся и внедряется, какие сценарии дают эффект, какие ошибки встречаются. Это не код и не маркетинговая брошюра — это **предметное знание**, на основе которого строятся продажи, обучение и интеграции.

## Основные идеи (v0.1.0)

### TimeList — NoTaker AI для совещаний

TimeList относится к классу систем **NoTaker AI**: специализированный агент, который из видеоконференций и офлайн-совещаний делает расшифровку, базу знаний встреч, автопротоколы и ответы на вопросы по конкретной встрече.

### Два режима развёртывания

- **Облако** — почасовая/годовая оплата, без оборудования.
- **On-premise** — свои серверы с GPU, выше безопасность, дороже внедрение.

### Главный канал продажи — живое демо

Бота приглашают на реальную переговорную встречу, клиент видит расшифровку в реальном времени. Это даёт больше доверия, чем слайды.

### Информационная безопасность как аргумент

Для российских юридических лиц передача аудио в зарубежные сервисы запрещена (152-ФЗ). TimeList работает в закрытом контуре: российские серверы, реестр отечественного ПО, on-premise.
